# Executive Memo

Use this skill when analysis needs to drive a business decision.

## Workflow

1. Start with the decision and answer.
2. Summarize key evidence, chart references, caveats, and alternatives.
3. Translate technical details into business implications.
4. End with recommendation, owner, deadline, and next analysis.

## Output

Return `Executive summary`, `Evidence`, `Caveats`, `Recommendation`, and
`Decision ask`.
