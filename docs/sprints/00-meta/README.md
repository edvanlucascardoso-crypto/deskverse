# Meta da execução

Esta pasta contém somente os contratos de coordenação do roadmap: manifesto, gates e instruções do Supervisor. Requisitos de produto permanecem nas sprints responsáveis.

Serviços MCP/API/worker externos seguem a [convenção de sprints de serviços](SERVICE_SPRINT_CONVENTION.md).

O manifesto é a fonte de ordem e dependências. `SPRINT_STATUS.md` registra o estado humano mais recente; os dois arquivos devem ser atualizados juntos quando uma sprint ou gate mudar.
