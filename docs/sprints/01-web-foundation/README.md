# Fase 01 — Fundação Web

Colocar o aplicativo web em funcionamento como base visual e técnica do Deskverse, com Next.js, componentes DOM, shadcn/ui, React Flow quando houver relações e Motion para transições.

## Ordem

1. SPRINT-01-00 — Bootstrap do aplicativo web
2. SPRINT-01-01 — Sistema visual e shell da aplicação
3. SPRINT-01-02 — Workspace principal do canvas
4. SPRINT-01-03 — Qualidade local e fluxo de entrega

Cada sprint entrega uma fatia demonstrável, registra integrações pendentes e mantém a experiência baseada em componentes DOM. Fixtures locais são permitidas quando ajudam a demonstrar a interface.

## Fora da fase

Não entram nesta fase persistência remota, autenticação, publicação externa, cobrança ou uma engine visual paralela. Essas decisões pertencem às fases indicadas no manifesto.
