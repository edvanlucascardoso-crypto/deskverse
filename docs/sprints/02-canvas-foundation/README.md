# Fase 02 — Fundamento do Canvas

Estabelecer o canvas full-screen como uma grade espacial única de logos/tiles de agentes, antes de adicionar interações avançadas. O visual deve lembrar um wall de agentes: tiles neutros, sem lanes ou colunas de Kanban, e cor somente quando houver atividade.

## Ordem

1. SPRINT-02-01 — Canvas full-screen e grade espacial de agentes
2. SPRINT-02-02 — Logos, estados neutros e hierarquia visual
3. SPRINT-02-03 — Composição única do wall e sheets contextuais
4. SPRINT-02-04 — Responsividade e densidade do wall

Cada sprint entrega uma fatia demonstrável, registra integrações pendentes e mantém a experiência baseada em componentes DOM. Fixtures locais são permitidas quando ajudam a demonstrar a interface.

## Fora da fase

Não entram nesta fase persistência remota, autenticação, publicação externa, cobrança ou uma engine visual paralela. Essas decisões pertencem às fases indicadas no manifesto.
