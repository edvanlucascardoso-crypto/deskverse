# Fase 11 — Integrações e Planejamento

Conectar ferramentas e canais externos ao fluxo de trabalho, mantendo autorização, aprovação, rastreabilidade e fallback claros.

## Ordem

1. SPRINT-11-01 — Criação visual assistida
2. SPRINT-11-03 — Canal Instagram
3. SPRINT-11-04 — Canal WhatsApp
4. SPRINT-11-05 — Conexões atribuições e inbox unificada
5. SPRINT-11-06 — Agenda de publicações
6. SPRINT-11-07 — Resumo diário e recomendações

SPRINT-11-02 foi adiada para SPRINT-15-19, onde a plataforma própria de imagem será construída sem bloquear integrações de canal nem o MVP.

A fase é executada na ordem indicada. Cada sprint apresenta o fluxo principal, estados recuperáveis, validações e integrações pendentes.

Não há exceção de dependência para o Designer do MVP. A infraestrutura própria de imagem foi transferida para a SPRINT-15-19; esta fase permanece posterior ao MVP.

## Limites

Regras e tipos ficam próximos da feature. Não se cria uma camada transversal prematura nem se muda a semântica do canvas para acomodar uma integração futura.
