# Prompt — Sheet: kit de arquitetura

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet do **kit modular de arquitetura do escritório Deskverse**: módulo de piso, parede reta e canto de parede. Mostre cada peça isolada em visão isométrica 3/4, com proporções compatíveis entre si e encaixes visualmente claros para modelagem modular no Blender.

Fundo neutro. Sem personagens, textos, logos ou decoração extra.
