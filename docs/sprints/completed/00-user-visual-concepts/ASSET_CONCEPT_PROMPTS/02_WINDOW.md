# Prompt — Sheet: janela

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet da **janela modular do escritório Deskverse**, pensada para encaixar nas paredes do cenário. Mostre frente, 3/4 e uma visão simples da espessura/encaixe. Mantenha o design simples e leve para modelagem 3D.

Fundo neutro. Sem personagens, textos, logos ou objetos extras.
