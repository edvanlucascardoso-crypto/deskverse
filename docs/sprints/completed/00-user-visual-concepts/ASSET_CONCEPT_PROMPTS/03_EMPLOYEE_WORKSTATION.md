# Prompt — Sheet: estação de funcionário

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet da **estação de trabalho padrão de funcionário do Deskverse**: mesa, cadeira e computador. Mostre o conjunto montado e os três componentes visualmente separáveis, em visão isométrica 3/4, com proporções coerentes para um personagem sentado.

Não gere teclado, mouse, gabinete ou acessórios como assets separados. Fundo neutro, sem personagens, textos ou logos.
