# Prompt — Sheet: estação do dono

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet da **estação do dono do Deskverse**: mesa um pouco maior que a estação padrão, cadeira e computador. Mostre o conjunto montado e os componentes visualmente separáveis em visão isométrica 3/4. Deve pertencer à mesma família visual da estação de funcionário, apenas com presença um pouco maior.

Fundo neutro. Sem personagens, textos, logos ou acessórios desnecessários.
