# Prompt — Sheet: conjunto de reunião

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet do **conjunto modular de reunião do Deskverse**: mesa de reunião e cadeira compatível. Mostre o conjunto montado, os componentes separados e uma sugestão de como a mesa pode ser repetida ou estendida para reuniões maiores, sem criar outra família de móvel.

Visão isométrica 3/4, fundo neutro, sem personagens, textos ou logos.
