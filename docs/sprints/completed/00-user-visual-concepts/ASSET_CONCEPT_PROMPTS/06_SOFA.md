# Prompt — Sheet: sofá

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet do **sofá de escritório do Deskverse**. Mostre frente, lateral e 3/4, mantendo proporções simples, leitura clara e escala compatível com os personagens e demais móveis.

Fundo neutro. Sem personagens, almofadas soltas, textos, logos ou decoração extra.
