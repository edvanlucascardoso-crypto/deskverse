# Prompt — Sheet: mesa de centro

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet da **mesa de centro do Deskverse**, compatível visualmente e em escala com o sofá. Mostre frente/lateral suficientes para entender altura, tampo, base e proporções, sempre em linguagem simples para modelagem 3D.

Fundo neutro. Sem personagens, objetos sobre a mesa, textos ou logos.
