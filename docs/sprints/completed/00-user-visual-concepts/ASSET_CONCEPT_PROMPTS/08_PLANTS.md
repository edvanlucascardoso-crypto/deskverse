# Prompt — Sheet: plantas de escritório

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet da **família de plantas de escritório do Deskverse** com no máximo 3 variações realmente úteis, compartilhando o mesmo vaso e a mesma linguagem visual. As variações devem ser simples o bastante para também poderem ser obtidas por escala, rotação ou pequenas alterações de folhas.

Visão isométrica 3/4, fundo neutro, sem personagens, textos ou logos.
