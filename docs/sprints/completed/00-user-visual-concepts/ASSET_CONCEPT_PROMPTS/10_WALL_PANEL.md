# Prompt — Sheet: painel de parede

Use **a imagem de referência anexada** como referência visual obrigatória. Reproduza a mesma linguagem de formas, materiais, cores, iluminação e acabamento.

Crie uma concept sheet de um **painel de parede modular do Deskverse** que possa funcionar como quadro, display ou painel informativo apenas trocando o conteúdo no jogo. Mostre frente, lateral e 3/4, com moldura e espessura simples.

Fundo neutro. Não coloque conteúdo legível no painel. Sem personagens, textos ou logos.
