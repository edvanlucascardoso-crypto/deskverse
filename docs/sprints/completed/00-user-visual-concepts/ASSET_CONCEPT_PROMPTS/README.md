# Assets da Sprint 00

Cada família de asset possui **sua própria concept sheet**. Em cada geração, envie somente:

1. a imagem de referência visual escolhida;
2. o prompt do arquivo da família.

Não é necessário anexar prompt mestre, art bible ou outros documentos.

## Sheets
- `01_ARCHITECTURE_KIT.md`
- `02_WINDOW.md`
- `03_EMPLOYEE_WORKSTATION.md`
- `04_OWNER_WORKSTATION.md`
- `05_MEETING_SET.md`
- `06_SOFA.md`
- `07_COFFEE_TABLE.md`
- `08_PLANTS.md`
- `09_STORAGE.md`
- `10_WALL_PANEL.md`

Peças pequenas como teclado, mouse, gabinete, lixeira, relógio, tapete e decoração simples não exigem concept próprio. As animações também não exigem imagens na Sprint 00.
