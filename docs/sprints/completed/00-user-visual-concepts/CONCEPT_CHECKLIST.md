# Concept Completion Checklist

Não iniciar modelagem final no Blender antes de concluir os itens abaixo.

## Referência visual
- [ ] a mesma imagem de referência visual foi usada como base em todas as gerações aprovadas
- [ ] nenhuma geração dependeu de prompt mestre ou arquivos auxiliares

## Personagens
- [ ] character lineup aprovado
- [ ] corpo-base e peças modulares coerentes

## Salas
- [ ] Initial: 6 mesas de funcionários em grid 3 × 2 + mesa do dono
- [ ] Startup: 12 posições de funcionários + mesa do dono
- [ ] Big Tech: 24 posições de funcionários + área do dono
- [ ] todas usam câmera isométrica 3/4 e arquitetura aberta
- [ ] **nenhuma sala contém personagens, agentes ou silhuetas humanas**

## Asset sheets
- [ ] kit de arquitetura
- [ ] janela
- [ ] estação de funcionário
- [ ] estação do dono
- [ ] conjunto de reunião
- [ ] sofá
- [ ] mesa de centro
- [ ] plantas
- [ ] armazenamento
- [ ] painel de parede

## Consistência
- [ ] mesma linguagem visual da imagem de referência
- [ ] mesma escala entre personagens, móveis e salas
- [ ] silhuetas legíveis em tela pequena
- [ ] assets viáveis como GLBs leves
- [ ] `docs/art/concepts/CONCEPT_APPROVED.md` criado
