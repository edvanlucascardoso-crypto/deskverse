# Sprint 00 — Concepts visuais no ChatGPT Work

## Objetivo
Fechar as referências visuais necessárias antes da modelagem em Blender.

## Regra de execução
Em **toda geração**, envie a imagem de referência visual escolhida e **um único prompt** desta sprint. Não anexe outros documentos do projeto.

A imagem anexada define o estilo. O prompt define somente o que deve ser criado.

## Ordem
1. Gere o `CHARACTER_LINEUP_PROMPT.md`.
2. Gere as salas `initial`, `startup` e `big-tech` **sem personagens**.
3. Gere as 10 famílias de assets, cada uma em sua própria sheet.
4. Confira `CONCEPT_CHECKLIST.md` e preencha `CONCEPT_APPROVAL_TEMPLATE.md`.

## Quantidade
- 1 character lineup
- 3 salas
- 10 asset sheets

Total: **14 gerações**.

Não gere concepts separados para teclado, mouse, gabinete, lixeira, relógio, tapete, pequenos enfeites, roupas isoladas ou animações.

## Gate
Somente após a aprovação crie `docs/art/concepts/CONCEPT_APPROVED.md` com `CONCEPT_APPROVED=true` e inicie as sprints Blender.
