# Sprints concluídas

Esta pasta reúne sprints e fases que já possuem entregáveis duráveis no
repositório. O material é mantido para consulta e auditoria; novas tarefas
devem ser executadas nas pastas de fases ativas.

## Fases arquivadas

Uma fase só deve ser movida para cá quando seus entregáveis e critérios de
aceite estiverem verificáveis. A mudança também deve ser refletida no
manifesto JSON/CSV e no índice de sprints.
